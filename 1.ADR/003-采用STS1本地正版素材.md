# ADR-003：v3 完善版使用 STS1 本地正版素材

- 日期：2026-08-06
- 状态：已实施（v0.3.0，待游戏内验证）

## 背景

用户拥有本地正版杀戮尖塔1，要求把幻影杀手（Phantasmal Killer）的十语言卡名/卡面文本、卡图、Buff 名称与图标都取自 STS1，替换进 STS2 模组。

## 决策（拟）

1. 文本：从 `desktop-1.0.jar` 的 `localization/<lang>/cards.json` 与 `powers.json` 提取，转换标记（`NL`→`\n`，`#y`→`[gold]...[/gold]`）后写入模组 pck 增量覆盖表。
2. 卡图：STS1 `images/1024Portraits/green/skill/phantasmal_killer.png`（500×380）放大 2× 到 1000×760，并生成 250×190 小图。
3. Buff：名称/图标作用于 `SHADOW_STEP_POWER`；建议同时作用于独占过渡 Buff `DOUBLE_DAMAGE_POWER`。图标取自 `powers/powers.png` 图集 `128/phantasmal`（87×86），缩放为 64×64 与 256×256。
4. 代码：新增 `PowerModel.PackedIconPath` / `ResolvedBigIconPath` / `Icon` / `BigIcon` 补丁（仅 `ShadowStepPower`）；既有 OnPlay/卡图补丁不变。

## 理由

- 用户拥有正版且明确要求使用游戏内资源；素材与官方美术风格一致。
- 500×380 恰好是 STS2 1000×760 的一半，无需裁切即可满幅使用。
- `DoubleDamagePower` 经全库检索确认仅由本卡链路使用，改名/换图标无副作用。

## 后果

- 模组包体积增加（卡图/图标合计约几十 KB，可接受）。
- 素材来自 STS1，仅供用户自用/模组分发；由用户自行确认素材政策。
- 用户已确认：采用方案 B（内容用 STS1、排版规范化）；新增 ita/pol/tha/tur，esp 与 spa 同内容；`DOUBLE_DAMAGE_POWER` 不改名称/图标；模组图标由用户自行提供。
