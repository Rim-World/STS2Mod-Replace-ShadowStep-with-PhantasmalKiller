# ADR-002：最小可用版 v0.1.0 实现

- 日期：2026-08-05
- 状态：已实施（待用户游戏内验证）

## 决策

1. 先交付最小可用版：仅简体中文、纯色占位卡图、只针对 v0.110.1；代码/素材结构已为后续十语言与正式卡图预留。
2. 行为替换采用 Harmony `Prefix` 整体替换 `ShadowStep.OnPlay`，只保留 `PowerCmd.Apply<ShadowStepPower>`（去掉弃牌）。
3. 卡图替换采用补丁 `CardModel.PortraitPngPath / Portrait / PortraitPath` 三个 getter，指向 `res://PhantomKillerMod/images/card_portraits/big/phantasmal_killer.png`；DLL 内嵌同一 PNG 作为加载兜底。
4. 文本采用模组 pck 增量本地化覆盖（`localization/zhs/cards.json`、`powers.json`），不写文本补丁。
5. 构建链路：`build.ps1` = dotnet build + Godot 4.5.1 `--import` + `--export-pack` + 拷贝到 `mods/PhantomKillerMod`。

## 理由

- 先跑通最小闭环，验证“加载 → 改名/改文 → 改效果 → 改卡图”整条链路后再扩展。
- 各部分均参考 RevertAnthony / BaseLib / 官方模板的已验证做法。

## 后果

- 当前只覆盖 v0.110.1 + 简体中文；107.1、其余语言、正式卡图待后续阶段。
- 若游戏内验证发现问题（如补丁签名不匹配、卡图未生效），在小范围内迭代修复。
