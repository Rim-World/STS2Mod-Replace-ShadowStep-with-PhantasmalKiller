- 001-E 是跨项目证据库，其中也记录了同一时期另外四个 mod（死割、尸爆、回收、进化）的取证，
  阅读时注意区分当前仓库的 `PhantomKillerMod` 与其它模组的记录。
- 003-T 的结论与模组代码无关，属于游戏版本行为，排查存档问题时优先查阅。
