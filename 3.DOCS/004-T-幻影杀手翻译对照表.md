# 004-T：幻影杀手翻译对照表（提案 v0.3，已获批准并按方案 B 实施）

> 本文件曾为提案；用户已于 2026-08-06 批准**方案 B**，并确认新增 ita/pol/tha/tur（esp 与 spa 同内容）。v0.3.0 已按本表实施并构建安装。

## 0. 说明

- 语言范围：14 种（现有 10 种 + 新增意大利语 ita、波兰语 pol、泰语 tha、土耳其语 tur）；另 STS2 的 `esp` 西语目录与 `spa` 写同一份内容，共 15 个语言目录。
- 转换规则（所有语言通用）：
  - `NL`（换行标记，仅日语出现）→ `\n`
  - `#y`（金色标记）→ `[gold]...[/gold]`
  - `#b`（蓝色动态数字标记，仅土耳其语出现）→ `[blue]{}[/blue]`
  - Buff 智能描述（smartDescription）按 STS2 的 `{Amount:...}` 语法组装，语法风格与 STS2 该语言现有文本保持一致（plural / plural(ru) / choose / choose(1)）。
- 下表“拟定最终文本”按**方案 B**（内容用 STS1 官方原文，排版规范化：补齐句末标点、修正笔误、清理多余空格）。方案 A / C 的定义见文末“审批区”。
- 当前模组 v0.2.0 实际使用的就是“STS1 原文 + 标记转换”（即方案 A 效果），这也是你看到繁中/韩语无句号的原因。
