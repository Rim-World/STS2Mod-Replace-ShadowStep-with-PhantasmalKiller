# 杀戮尖塔2mod 将暗影步替换为幻影杀手

## ① 环境

本 mod 不依赖任何基础 mod。

本 mod 支持 public beta 110 版本与 default 107 版本。

## ② 15 种语言支持

亚洲：简体中文 / 繁体中文 / 日语 / 韩语 / 泰语 / 土耳其语

欧洲与美洲：英语 / 葡萄牙语（巴西）/ 西班牙语（拉美）/ 西班牙语 / 法语 / 俄语 / 德语 / 意大利语 / 波兰语

文本标签按首字母顺序，依次为 deu、eng、esp、fra、ita、jpn、kor、pol、ptb、rus、spa、tha、tur、zhs、zht。

文本均来自《杀戮尖塔 1》，仅作简单格式调整，可能有少量错误。

## ③ 效果

将游戏中的“暗影步”卡牌的效果、卡名、卡面图片、卡面文本、buff 图标、buff 动态文本更换为与《杀戮尖塔 1》中卡牌“幻影杀手”相同。

本 mod 采用直接在“暗影步”原卡牌上进行修改的方法生效，并非生成新卡牌 + 禁用旧卡牌。

本 mod 影响存档：在 mod 开启时，所有历史记录中的“暗影步”卡牌都会被更换为“幻影杀手”卡牌；关闭 mod 后会恢复原状。

## ④ 影响（基于本人游戏理解）

在原版游戏高进阶（A10）难度下，大多数对局中，对于静默猎手职业，幻影杀手仅仅比暗影步略强；对于其它职业，当你有保留手牌的手段时，幻影杀手显著强于暗影步。

在原版游戏低进阶（A0）难度下，大多数对局中，对于全体职业而言，幻影杀手显著强于暗影步。

## ⑤ 兼容性与 Bug

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着版本变化而失效。但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。

当你开启本 mod，且有一把正在进行中的游戏未结束就切换/升级游戏版本时，可能导致正在进行中的那一把游戏无法正常读取，只能放弃。

# STS2Mod-Replace-ShadowStep-with-PhantasmalKiller

## 1. Environment

This mod does not depend on any base mod.

This mod supports the Public Beta 110 version and the Default 107 version.

## 2. 15 Languages Supported

Asia: Simplified Chinese / Traditional Chinese / Japanese / Korean / Thai / Turkish

Europe & the Americas: English / Portuguese (Brazil) / Spanish (Latin America) / Spanish / French / Russian / German / Italian / Polish

The text tags, in alphabetical order, are: deu, eng, esp, fra, ita, jpn, kor, pol, ptb, rus, spa, tha, tur, zhs, zht.

All texts are taken from Slay the Spire 1, with only simple formatting adjustments; there may be minor errors.

## 3. Effects

Replaces the effect, card name, card art, card text, buff icon, and buff dynamic text of the game's "Shadow Step" card with those of the "Phantasmal Killer" card from Slay the Spire 1.

This mod works by modifying the original "Shadow Step" card directly, rather than creating a new card and disabling the old one.

This mod affects save files: while the mod is enabled, all "Shadow Step" cards in historical records will be replaced with "Phantasmal Killer" cards; disabling the mod restores the original state.

## 4. Impact (Based on My Understanding of the Game)

At higher ascension (A10) in the vanilla game, in most runs, Phantasmal Killer is only slightly stronger than Shadow Step for The Silent; for other characters, when you have ways to retain cards in hand, Phantasmal Killer is significantly stronger than Shadow Step.

At lower ascension (A0) in the vanilla game, in most runs, Phantasmal Killer is significantly stronger than Shadow Step for all characters.

## 5. Compatibility & Bugs

This mod is written with minimal dependencies, so under normal circumstances it is compatible with most mods and unlikely to break as the game version changes. However, compatibility is not guaranteed with pirated copies, modified versions, mobile versions, outdated versions, niche mods, or secondary mods.

If you enable this mod and switch/upgrade the game version while a run is still in progress without finishing it, the in-progress run may fail to load properly and can only be abandoned.
